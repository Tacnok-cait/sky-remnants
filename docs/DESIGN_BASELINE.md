# Sky Remnants Design Baseline

## Fixed technical baseline

- Minecraft Java Edition 1.21.1
- NeoForge 21.1.x
- Java 21
- Gradle
- Mod ID: skyremnants

## Core design principles

- Sky islands are the world form, not the whole gameplay loop.
- Preserve Minecraft-style freedom and intuitive interaction.
- Avoid mandatory quest trees, classes, power networks, and complex maintenance.
- Automation should remove repetitive work, not create maintenance work.
- Machines do not wear out; problems are missing materials, blocked workspaces, missing tools, or full output.
- Exploration, building, automation, and combat are parallel player choices.

## Scope boundary

The first release focuses on the complete 0–6 hour vertical slice:

- island survival;
- resource loops;
- farming and animal automation;
- monster resource automation;
- logistics;
- challenges;
- first airship and exploration.

Long-term expansion such as advanced islands, endgame systems, larger ships, bosses, and special dimensions remains outside this baseline.
